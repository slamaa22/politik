# ORATOR // Obama-Rhetoriktrainer

Politischer Rhetorik- & Charisma-Trainer auf Deutsch – inspiriert von Barack Obamas Redekunst (Kadenz, strategische Pausen, Dreiklang, Anapher, Kontrast-Brücken, Story of Self → Us → Now und Ruhe im Gegenwind).

## Starten

```bash
npm start
```

Danach im Browser öffnen: `http://127.0.0.1:3456`

## Enthaltene Module

1. **Eingangstest (Baseline-Diagnose):** 3-teilige Standortbestimmung (Spontanrede, Kadenz-Ablesen, Brückenbau mit Pflichtwörtern) inklusive 6-Achsen-Kompetenzradar und individuellem Trainingsplan.
2. **Spontanrede-Studio:** Zufallsthemen aus 6 Politikfeldern, Vorbereitungs- & Rede-Timer, Live-Audio- & Pausenanalyse.
3. **Zufällige Rede ablesen (Teleprompter):** 10 deutsche Redepassagen mit Obama-Regiezeichen (`[PAUSE]`, `▲`, `●`), WPM-Regler (Sweetspot 115–135 WPM), Vollbild, Spiegelung und eigener Redebibliothek.
4. **Thema & Pflichtwörter:** Zufallsthema + 3–5 Pflichtwörter (3 Schwierigkeitsstufen) mit automatischer Erkennung im Transkript.
5. **Obama-Drills & Gegenwind:** „Die Obama-Sekunde“ (Live-Pausenzähler), Stilmittel-Labor, *Story of Self → Us → Now*-Builder (für deine eigene authentische Geschichte) und Townhall-Gegenwind-Simulator.
6. **Obama-Playbook:** Die 7 Säulen von Obamas Rhetorik mit deutschen Formulierungs-Vorlagen.
